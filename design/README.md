## How to export from Adobe XD
1. Open `Agg.Ecommerce AnimalAmo_22-02-24.xd`.
2. Select the artboard (e.g. **Homepage – 4**).
3. `File → Export → Selected` (or ⌘/Ctrl+E) → **PNG**, **1x**, Design (not @2x — the canvas is already 1920px wide).
4. Save as `home.png` into this `design/` folder.

The full-res source photos are already extracted from the .xd; I pull + optimize the
right ones per section while matching your PNG. PNGs here are gitignored (reference only).
