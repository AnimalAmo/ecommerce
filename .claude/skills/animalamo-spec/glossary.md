# Glossary — AnimalAmo Functional Analysis

Italian terms kept as-is (they are the live product names). (Ch N) marks source section.

- **Animal Holiday** — legacy name for the hotels section; rebranded to **Vacanze** (Ch1).
- **Animal Network** — social wall; users post with thematic tags. Rebranded from *Community* (Ch1, Ch2).
- **Animal Times** — informational blog (normative, trasporti, pet-friendly tips). Rebranded from *News*; launched early for SEO (Ch1, Ch2).
- **Attività e Servizi** — services section; renamed from *Esperienze* to avoid confusion with user stories (Ch1).
- **Al completo / Disponibile** — partner availability states for inventory (Ch2).
- **Caparra / Checkout 3 fasi** — checkout flow: Dati → Pagamento (Stripe) → Conferma (Ch2).
- **Fidelizzazione (punti)** — loyalty points earned per purchase → discounts/perks (Ch1, Ch2).
- **Geolocalizzazione** — user-position detection to filter results by proximity (Ch3).
- **IA / Intelligenza Artificiale** — assistive auto-responder for support + first-line request handling (Ch1).
- **Identità Cromatica** — color system: Giallo=primary, Azzurro=secondary/chat, Magenta=tags/highlights (Ch1).
- **iCal** — future/roadmap calendar sync with Booking + Airbnb (Ch3).
- **Iubenda** — third-party privacy/consent management provider (Ch3).
- **Licenza di apertura** — mandatory partner opening-license upload during onboarding (Ch1, Ch3).
- **Logica Smartbox** — promotional bundles requiring partner explicit opt-in consent (Ch1). See also *Smartbox* booking type.
- **Modulo Partner (B2B)** — supplier ops: inventory, cancellation policy, bookings dashboard (Ch2).
- **Modulo Superadmin** — total control: users/partners, moderation, banners, DB + economic flows (Ch2).
- **Modulo Utente (B2C)** — end-user booking: smart search, detail, points, checkout (Ch2).
- **Onboarding Partner (10 step)** — 10-step structure entry: room types, prices, cancellation policy, license upload (Ch1).
- **Policy di Cancellazione** — partner-selectable windows: 30 / 15 / 7 giorni / 24 ore (Ch2).
- **Registrazione Utente (4 step)** — Dati personali → Cellulare+password → Indirizzo → Dati animale (Ch1).
- **Ricerca Intelligente** — map + distance sort; zero-result → similar alternatives fallback (Ch2).
- **Scheda Dettaglio** — listing page: photos, human+animal services, FAQ, reviews (Ch2).
- **Smartbox (tipo prenotazione)** — one of the booking types in partner dashboard: Vacanze, Eventi, Attività, Smartbox (Ch2).
- **Split payment** — Stripe feature splitting funds platform-vs-partner (Ch3).
- **Stripe** — payment provider (Ch2, Ch3).
- **Trova il tuo professionista** — module to search trainers (addestratori) + pet-sitter (Ch1).
- **Vacanze** — live name for the hotels/holiday section (formerly Animal Holiday/Holiday) (Ch1).
